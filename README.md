# TicTacToe
A two-player Tic-Tac-Toe game built with Java AWT, featuring a clickable board, alternating turns, and win detection.
# How to play
Two players take turns clicking an empty square on the 3×3 board to place an X or an O. The first player to get three in a row horizontally, vertically, or diagonally wins.
# Run locally
1. Install a Java Development Kit (JDK).
2. Clone or download this repository and open the project folder in VS Code.
3. Open tictactoe.java and Run.
# What I practiced
I had lots of fun learning how to build a desktop interface with Java AWT components, responding to button clicks with ActionListener, and checking the board for winning combinations.
